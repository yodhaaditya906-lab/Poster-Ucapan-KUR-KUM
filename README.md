## 📌 Tentang Aplikasi

Aplikasi **Template Kartu Ucapan & Poster Booking KUR/KUM** dirancang khusus untuk mempermudah dan mempercepat tim publikasi serta pegawai di lingkungan **Micro Banking Region V / Jakarta 3** dalam membuat kartu ucapan dan materi apresiasi visual (*champion poster*) atas pencapaian booking pinjaman **Kredit Usaha Rakyat (KUR)** dan **Kredit Usaha Mikro (KUM)** secara instan berstandar branding resmi Bank Mandiri.

---

## ✨ Fitur Unggulan

- 🎨 **Rendering Canvas Interaktif:** Menggunakan HTML5 Canvas untuk menghasilkan komposisi poster berkualitas tinggi secara instan tanpa perlu software grafis berat seperti Photoshop.
- 📐 **Format Siap Pakai:** Preset rasio landscape dan portrait yang siap dibagikan ke WhatsApp Group, Instagram Story, maupun dicetak fisik.
- ⚡ **Kustomisasi Fleksibel:** Pengisian form instan untuk Nama Pegawai, NIP, Cabang/Unit Kerja, Nominal Booking (Rp), dan Foto Profil Pegawai.
- 📥 **Ekspor Gambar Sekali Sentuh:** Download langsung dalam format PNG resolusi tinggi (*High-DPI Ready*).
- 🏛️ **Brand Guidelines Bank Mandiri:** Menggunakan palet warna korporat resmi (*Mandiri Blue, Mandiri Gold/Yellow*) dan tipografi standar perbankan.

---

## 🚀 Menjalankan Secara Lokal

1. **Clone repository ini:**
   ```bash
   git clone https://github.com/yodhaaditya906-lab/Poster-Ucapan-KUR-KUM.git
   cd Poster-Ucapan-KUR-KUM
   ```

2. **Jalankan server lokal:**
   ```bash
   node server.js
   ```

3. **Buka di browser:**
   Akses `http://localhost:8086/`
